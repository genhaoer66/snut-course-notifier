# 课格界面设计规格（v1）

这是 2026-10 界面重写时的设计规格，实现以 `web/` 为准。示意中的课程、教师与教室均为占位。

> 读者：落地工程师。旧视觉（极光背景、玻璃卡片、鲸鱼标记、靛蓝主色、飞入诗句）**全部废弃**。
> 功能以旧版 `web/app.js` 为准做到对等，见第 7 节。后端零改动。
> 所有数值可直接落成 CSS；对比度由 WCAG 2.x 相对亮度公式实算。

---

## 1. 设计理念与品牌

- **站名**：课格（读 kè gé）。**副标题**：陕西理工大学 · 班级课表。
  - `<title>`：`课格 · 陕西理工大学班级课表`；`og:site_name`：`课格`。
  - 含义：课表就是一格一格的；首页只回答「今天这几格」。两个字，favicon 旁、微信分享卡片里都不截断。
- **气质关键词**：清楚、安静、像车站时刻表。不做装饰背景，不做渐变，不做毛玻璃。
- **使用场景与对应决定**：
  1. 早上 7 点在床上、赶路时单手看「今天几门、第一节在哪」：今日视图首屏（360×640 内）必须露出日期、门数、第一门课的**节次 + 教室**，无需滚动。
  2. 课间 10 分钟找下一节教室：教室是卡片里第二醒目的信息（仅次于课名），带定位图标，字号 15px/500。
  3. 偶尔看整周或别的周：周视图一屏放下周一到周五 11 节，手机上不横滑。
- **主色**：松石绿 `#0D7268`（浅）/ `#3FC8B7`（深）。理由：与旧靛蓝明确区分；绿色在课程色板中只占一个槽，品牌色与课程色不易混淆；在白底 5.79:1，可直接当文字色。

## 2. 设计 token

所有 token 写在 `:root`，深色写在 `@media (prefers-color-scheme: dark) { :root { … } }`。
**决定：不提供手动深浅切换**，只跟随系统。理由：微信内置浏览器和系统浏览器都跟随系统；多一个开关多一份 localStorage 状态和首帧闪烁问题；旧版同样不提供，没人反馈过。`<meta name="color-scheme" content="light dark">` 必须加，让表单控件和滚动条跟着变。

### 2.4 断点

| 名称 | 范围 | 主要变化 |
|---|---|---|
| `sm`（默认） | 0–599px | 单栏，分段控件切「今日 / 本周」 |
| `md` | 600–1023px | 单栏，内容最大宽 720px 居中；今日卡片仍单列 |
| `lg` | ≥1024px | 双栏同屏：左 360px 今日，右周课表；隐藏分段控件；内容最大宽 1200px |

写法：`@media (min-width: 600px)`、`@media (min-width: 1024px)`，移动优先。

## 3. 信息架构与屏幕

页面状态互斥：`boot`（加载）→ `gate`（口令）/ `fatal`（错误）/ `app`。`app` 内两个视图：`today`、`week`。课程详情是覆盖层 `sheet`。

### 3.1 顶栏（app 内常驻，sticky top:0，高 56px，底 1px `--border`，背景 `--bg`）

```
┌──────────────────────────────────────────┐ 56px
│ [■] 课格            ( 今日 | 本周 )       │
└──────────────────────────────────────────┘
```
- 左：logo 24×24 + 站名 17px/600，间距 8px。站名是 `<h1>`。
- 右：分段控件。总高 36px，外框 `--surface-2`、`--r-pill`、内边距 3px；每段宽 64px、高 30px、13px/500。
  - 未选：文字 `--text-2`，透明底。悬停：文字 `--text`。按下：底 `--border`。
  - 选中：底 `--surface`，文字 `--text`，`box-shadow: 0 1px 2px rgb(0 0 0 / .08)`（深色用 1px `--border`）。
  - 点击热区用透明 `::before` 扩到 44px 高。
  - 语义：`role="tablist"`，按钮 `role="tab" aria-selected aria-controls`，面板 `role="tabpanel"`；←/→ 键在两个 tab 间移动焦点并切换（roving tabindex）。
- `lg` 下分段控件 `hidden`，右侧改显「每日 07:00 自动更新」13px `--text-3`。`sm/md` 下这句挪到页脚。

### 3.2 今日视图（sm，360×640 首屏）

```
┌──────────────────────────────────┐
│ 顶栏                              │ 56
├──────────────────────────────────┤
│ 10月24日 星期六 · 第 8 周          │ 13px text-2, mt 20
│ 今天 3 门课                        │ 28px/600, mt 4
│ ┌──────────────────────────────┐ │ mt 16
│ │▌ 1–2节   汽车构造             │ │ 卡片 min-h 76
│ │▌ 08:00   ⌖ 7号楼 7203         │ │
│ │▌         教师 A               │ │
│ └──────────────────────────────┘ │ 间距 8
│ ┌──────────────────────────────┐ │
│ │▌ 3–4节   机械设计 …           │ │
│ └──────────────────────────────┘ │
│ 今日一句：会当凌绝顶……  —— 杜甫  │ 13px text-3, mt 24
│ 页脚                              │
└──────────────────────────────────┘
```
- **日期行**：`M月D日 星期X · 第 N 周`。N 为 `current_week`；无则省略「· 第 N 周」。
- **主标题**（规则沿用旧版）：未配置开学日 →「本学期课表已准备好」；有课 →「今天 N 门课」；无课且周六日 →「周末，好好休息」；无课工作日 →「今天没有课」。
- **课程卡** `<button class="course">`（整卡可点开详情）：
  - 背景 `--surface`，1px `--border`，`--r-md`，内边距 12px 16px 12px 20px，最小高 76px。
  - 左侧 4px 课程色竖条（`--c-bar`），绝对定位 top/bottom 12px、left 8px，圆角 2px。
  - 左列宽 56px：节次 `1–2节` 15px/600 `--text`（数字用 `--font-num`）；若 `periods` 有效，下方显示起始时间 `08:00` 12px `--text-3`。
  - 右列：课名 17px/600 `--text`，最多 2 行（`-webkit-line-clamp:2`）；教室行：14px 定位图标 + 教室 15px/500 `--text-2`，缺失写「教室待定」；教师 13px `--text-3`，缺失写「教师待定」。行距 2px。
  - 状态：悬停（仅 `@media (hover:hover)`）边框 `--text-3`；按下底 `--surface-2`；`:focus-visible` 焦点环。无选中/禁用态。
- **无课空状态**（替代卡片列表）：一张 `--surface` 卡，内边距 20px：
  - 第一行 15px/600 `--text`：空状态说明（旧 `emptyHint`：整周无课 →「第 N 周整周无常规课，多为集中实践周或假期」；周末 →「周末没有安排课程」；否则「这一天没有排课」）。
  - 分隔 1px，下面「下一次上课」块：标签 12px `--text-3`；内容 15px：`明天 / 周X · 第 a–b 节 · 课名 · 教室`。7 天内都没有 →「接下来一周无课，集中实践周，不上常规课」。整块是按钮，点开该课详情。
- **未配置开学日**：卡片列表位置显示提示卡，底 `--surface-2`，文字 15px `--text-2`：「尚未配置本学期第一周日期，暂时无法按教学周过滤。」
- **今日一句**（旧版诗句保留，降级为静态一行）：今日视图底部，13px/20px `--text-3`，`诗句 —— 出处`，换行允许。无动画。
- 今日视图永远基于 `current_week` 和今天，不受周视图翻周影响（与旧版一致）。

### 3.3 周视图（sm）

```
┌──────────────────────────────────┐
│ 顶栏                              │
├──────────────────────────────────┤
│ [‹]   第 8 周 · 10/19–10/25  [›]  │ 周次条 48px, mt 12
│        回到本周（非本周时出现）     │
│ 14 次课 · 5 天 · 常在 7203         │ 13px text-2, mt 8
├──┬─────┬─────┬─────┬─────┬─────┤
│  │周一 │周二 │周三 │周四 │周五 │ 表头 44px
│  │10/19│10/20│ ... │     │     │
│  │6节  │4节  │     │     │     │
├──┼─────┼─────┼─────┼─────┼─────┤
│1 │汽车 │     │     │     │     │ 每节 48px
│2 │构造 │     │     │     │     │ (连堂合并)
│  │7203 │     │     │     │     │
│3 │     │ ... │     │     │     │
│… 共 unit_count 行（当前 11）      │
└──┴─────┴─────┴─────┴─────┴─────┘
```
- **周次条**（`<nav aria-label="周次">`）：
  - 左右箭头按钮各 44×44，图标 20px，`--text-2`；悬停底 `--surface-2`；按下底 `--border`；**禁用**（已到第 1 周 / 已到最大周）时 `opacity:.38`、`disabled` 属性、不可聚焦。最大周 = 数据中出现的最大周次（无数据时 17）。旧版无上限，新版加上。
  - 中间标签按钮：`第 N 周` 17px/600 + 空格 + `M/D–M/D` 13px `--text-3`（无开学日只显示「第 N 周」）。若 N = 本周，右侧附 `本周` 徽标：12px/500，`--accent` 文字，`--accent-soft` 底，`--r-pill`，内边距 2px 8px。
  - 非本周时标签下方显示「回到本周」文字按钮（13px `--accent`，高 32px，热区扩到 44px）；点中间标签同样回到本周（保留旧行为）。本周时该按钮不渲染。
- **周概览一行**：`{本周课程} 次课 · {上课日} 天 · 常在 {常用教室}`，`aria-live="polite"`，翻周时读屏会读出。无课：「这周没有常规课」。（旧版「节次总数」是常量 unit_count，信息量为零，改为表格行数本身体现，见第 7 节。）
- **表格**（真 `<table>`，`<caption class="sr-only">第 N 周课表</caption>`）：
  - 宽度 100%，`table-layout: fixed`；首列（节次号）24px；其余列等分。360px 屏下每列 ≈ 62px，**5 列不横滑**。
  - 列数：周一至周五恒显；若任何课程 `day ≥ 5`，补到 `max(day)+1` 列，并允许外层 `overflow-x:auto` 横滑，日列 `min-width: 56px`。只有这时才显示「左右滑动查看周末」提示（12px `--text-3`，表格下方），判断条件同旧版 `scrollWidth > clientWidth`。
  - 表头 `<th scope="col">`：`周一` 12px/500 `--text-2`；下面日期 `10/19` 11px `--text-3`；再下面当日节次数 `6节` 11px `--text-3`（0 时显示 `—`）。今天列（仅显示本周时）：表头文字 `--accent`，整列单元格底 `--accent-soft`。
  - 行头 `<th scope="row">`：节次号 12px `--text-3`，居中；若 `periods` 有效，节次号的 `title` 和 `aria-label` 带时间。
  - 行高 48px；`border-collapse: separate; border-spacing: 2px`；表格底 `--surface`；空单元格透明、无边框，只在第 2、4、6、8 节所在行下方画 1px `--border` 横线（大节分界），避免满屏格子。
  - 连堂同一课合并 `rowspan`（算法同旧版）。
  - **课程块** `<button>`：填满单元格（`height:100%`），`--r-sm`，内边距 4px，底 `--c-bg`，左 3px 实线 `--c-bar`，文字 `--c-text`；课名 12px/500/16px，最多 3 行（`line-clamp`，单节课 2 行）；教室 11px/14px，最多 1 行省略号。`aria-label="周二 第3–4节 机械设计，7号楼7203"`。按下 `filter: brightness(.95)`（深色 `1.12`）；焦点环内缩 `outline-offset:-2px`。

### 3.4 课程详情（sheet）

```
sm：底部弹层                       lg/md：居中对话框 440px
┌──────────────────────────────────┐
│            ───                   │ 拖拽把手 36×4（仅装饰）
│ 周二 · 第 3–4 节            [×]   │ 13px text-3 / 关闭 44×44
│ 机械设计                          │ 20px/600
│ ─────────────────────────────── │
│ ⌖ 教室   7号楼 7203               │ 每行 min-h 44, 15px
│ ☺ 教师   教师 A                    │
│ ▦ 周次   第 1–8，10–16 周（共 15 周）│
│ ─────────────────────────────── │
│ 本周排课                          │ 12px/500 text-3
│ ▌周二  第 3–4 节   7号楼 7203       │ 当前这条加粗
│ ▌周四  第 1–2 节   7号楼 7105       │
└──────────────────────────────────┘
```
- 结构：`<div role="dialog" aria-modal="true" aria-labelledby="sheet-name">`。不用 `<dialog>` 元素（部分安卓微信内核支持不全）。
- sm：贴底，宽 100%，最大高 85vh，可内部滚动；上两角 `--r-lg`；内边距 8px 20px `calc(20px + env(safe-area-inset-bottom))`。md/lg：居中，宽 440px，`--r-lg` 四角，内边距 24px。
- 标题左侧 4px×20px 课程色条，与卡片一致。
- 详情行：图标 18px `--text-3`，标签 13px `--text-3` 宽 40px，值 15px `--text`；教室缺失「待定」，教师缺失「—」，周次用旧 `weekText`（区间用 `–` U+2013，分隔用中文逗号）。
- 本周排课：同名课程在**当前查看周**的所有排课，按星期、节次排序；每行 40px，`星期 / 节次 / 教室` 三列（48px / 80px / 余下）；被点开的那条 600 字重。列表为空时整块隐藏。
- 关闭：× 按钮、点遮罩、Esc。打开时焦点移到 × 按钮，Tab 在弹层内循环，关闭后焦点回到触发它的课程按钮；打开时 `body` 加 `overflow:hidden`。

### 3.5 登录页（gate）

```
┌──────────────────────────────────┐
│                                  │ 上留白 = 18vh
│              [■]                 │ logo 48×48
│              课格                 │ 20px/600, mt 12
│     陕西理工大学 · 班级课表        │ 13px text-3, mt 4
│  ┌────────────────────────────┐  │ mt 32
│  │ 访问口令                    │  │ label 13px/500 text-2
│  │ [••••••••            ]     │  │ 输入框 48px
│  │ 口令不对                    │  │ 错误 13px danger, role=alert
│  │ [        进入课表         ] │  │ 按钮 48px, mt 16
│  └────────────────────────────┘  │ 卡片宽 min(100%, 360px)
│   口令在班级群公告里               │ 12px text-3, 居中

```
- 卡片：`--surface`，1px `--border`，`--r-lg`，内边距 24px。页面底 `--bg`。
- `<label for="gate-input">访问口令</label>` 必须可见（替代旧版只有 placeholder）。输入框 `type=password autocomplete=current-password`，16px 字号（防 iOS 缩放），1px `--border`，`--r-md`，内边距 0 12px；聚焦边框 `--accent` + 焦点环；错误时边框 `--danger`、`aria-invalid="true"`、`aria-describedby` 指向错误文字。
- 主按钮：底 `--accent`，字 `--on-accent` 15px/600，`--r-md`，宽 100%。悬停 `filter: brightness(1.06)`；按下 `brightness(.92)`；**提交中**：`disabled`、文字改「正在验证…」、`aria-busy="true"`；禁用 `opacity:.5`。
- 错误文案直接用后端 `error` 字段（「口令不对」「口令错误次数过多，请 N 秒后再试」）；网络失败「网络连接失败，请检查网络后重试」。
- **锁定态**（HTTP 429 / `code:"locked"`）：从 `error` 中用 `/(\d+)\s*秒/` 取秒数，输入框与按钮 `disabled`，按钮文字每秒刷新「请 N 秒后再试」，归零后恢复。解析不到数字时按 300 秒处理（`LOCKOUT_SECONDS`）。
- **令牌过期**：本地有令牌但 `/api/timetable` 回 401 → 清除令牌，登录页错误位显示「口令已更新或登录已过期，请重新输入」（`--warn` 色）。本地无令牌的 401 不显示任何错误。
- 底部提示「口令在班级群公告里」12px `--text-3`。

### 3.6 加载 / 空 / 错误状态

- **加载（boot）**：顶栏不渲染。页面中央偏上（top 18vh）显示 logo 48px + 「正在加载课表…」13px `--text-3`；下方 3 条骨架条（宽 100%/100%/60%，高 76px，间距 8px，`--surface-2`，`--r-md`）模拟今日卡片。骨架有 1.2s 透明度脉动（.6↔1），减弱动效时不脉动。`aria-busy="true"` 放在 `<main>`。
- **错误（fatal）**：居中，48px 断云图标 `--text-3`；标题 17px/600「暂时无法加载课表」；说明 15px `--text-2`：用后端 `error`，若 `code==="no_data"` 再显示 `hint`（13px `--text-3`，即「服务器上的抓取任务可能尚未运行过」）；网络异常「暂时连不上服务器，请检查网络后重试。」；其他状态「服务器返回了 {status}」。按钮「重新加载」：次级按钮样式（透明底、1px `--border`、`--text`、高 44px、内边距 0 20px、`--r-md`），带刷新图标。
- **空**：见 3.2 无课状态、3.3「这周没有常规课」（表格照常画出空表，不隐藏，避免被当成加载失败）。
- **锁定**：见 3.5。

### 3.7 页脚（今日视图与周视图底部，lg 在两栏下方通栏）

- 13px/20px `--text-3`，上边 1px `--border`，上下内边距 16px，居中，每项一行（sm）/ 用「·」连成一行（≥600px）。

## 5. 交互与动效

| 场景 | 动效 | 时长 / 缓动 |
|---|---|---|
| 今日 ↔ 本周切换 | 新面板 `opacity 0→1` + `translateY(4px→0)`；旧面板直接隐藏 | 160ms `cubic-bezier(.2,0,0,1)` |
| 翻周 | 表格 `tbody` 透明度 .4→1，不做位移 | 120ms `ease-out` |
| 底部弹层打开 | `translateY(100%→0)` + 遮罩 0→1 | 220ms `cubic-bezier(.2,0,0,1)` |
| 弹层关闭 | 反向 | 160ms `cubic-bezier(.4,0,1,1)` |
| 居中对话框（≥600px） | `scale(.98→1)` + 透明度 | 180ms 同上 |
| 按钮按下/悬停 | 背景色、边框色过渡 | 100ms `linear` |
| 骨架脉动 | 透明度 .6↔1 | 1200ms `ease-in-out` 无限 |

- 只动 `opacity` 和 `transform`，不动布局属性。
- **手势：不做任何横滑翻周、不做下拉刷新、不做弹层下拉关闭。** 理由：iOS 微信左边缘右滑是「返回」，安卓有系统返回手势，横滑翻周会误触；有周末列时表格本身要横滑，二者冲突。翻周只靠按钮和键盘。
- 键盘：在周视图且焦点不在输入框时，`←` / `→` 翻周（`[` `]` 不做），`Home` 回本周。Esc 关弹层。
- `prefers-reduced-motion: reduce`：所有 `transition-duration`、`animation-duration` 设为 `0.01ms`，骨架不脉动，弹层直接出现。
- `visibilitychange` 回到前台时重新渲染（跨过零点后「今天」要变），保留旧行为；不轮询，不重新请求接口。

## 9. 实现注意事项

### 9.1 坑

1. **ID 与旧 JS 不兼容**：这是重写，`app.js` 一并重写；但保留函数 `weekOf / weekDates / unitText / weekText / coursesOn / meetingsOf / hueOf 的哈希` 的逻辑与测试行为，别重新发明。
2. **「下一次上课」跨周 bug（旧版就有）**：旧 `renderHeroNext` 往后找 7 天时一律用 `currentWeek` 过滤，周六日看「下周一」会拿本周的周次去筛。新实现：目标日的周次 = `currentWeek + floor((今天星期索引 + offset) / 7)`。
3. **「今天」用本机时钟，周次用服务器 `current_week`**：两者跨零点可能不一致。保持旧做法（页脚提示），但 `today` 星期索引应改用 `server_today`（存在时），否则本机时间错的同学看到的是错日子的课。
4. **`periods`**：只在 `Array.isArray(periods) && periods.length >= unit_count` 且每项为 `["HH:MM","HH:MM"]` 时使用；否则完全不显示时间。不做「正在上课」高亮。
5. 课程色靠 `data-tone` + CSS，别再在 JS 里拼 `oklch()`（旧版 oklch 在 iOS 15.3 以下、部分 X5 内核不支持，会整块无色）。
6. 所有课程名、教室、教师只用 `textContent` / `setAttribute`，`aria-label` 拼接也走 `setAttribute`。
7. iOS 输入框字号 < 16px 会自动放大页面，口令框必须 16px。
8. 底部弹层 `max-height: 85vh` 在 iOS 微信里 vh 含工具栏，用 `85dvh` 并以 `85vh` 作回退。
9. sticky 顶栏 + `overflow-x:auto` 的周表：横滑容器不能是 sticky 元素的祖先，否则 sticky 失效。
10. 隐藏面板用 `hidden` 属性，CSS 中凡是给这些元素设 `display` 的，加 `[hidden]{display:none !important}`。
11. 本地预览 `{OG_BASE}` 会替换成空串，OG 图变相对路径，属正常。
