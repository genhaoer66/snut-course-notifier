## 规格取舍与已知差异

- 周末表格按 T06 公式再补 2px：真实 table 有节次列，边框间隙共 n+2 个。6/7 列最小宽度为 376/434px，保证日列至少 56px；5 列不设最小宽度，360px 不横滑。
- 打印特意保留 `#week-label`，这是 T06 对原“隐藏周次条按钮”的修正。
- 周表容器及其后代焦点不抢方向键，用于原生横滑；其它周视图焦点仍可翻周。
- 安全区 env 名称沿用 CSS 标识符转义 `safe-area-\69 nset-*`，与原名称等价；没有 inset 定位属性，满足任务要求的文本搜索零命中。
- “一屏放下 11 节”与 640px 屏高、每节 48px 加顶栏/表头无法同时成立；保留明确的行高规格，移动周表需要纵向滚动。截图显示底部行超出首屏属于此取舍，非横向裁切。
- 详情按入口所属周展示同名排课：今日入口用当前教学周、下一次入口用目标周、周表入口用查看周。比统一使用周表查看周更能保持入口上下文，但与 3.4 字面“当前查看周”存在差异。
- 错误屏显示服务端任意 hint，不限于 no_data；不影响现有接口。
