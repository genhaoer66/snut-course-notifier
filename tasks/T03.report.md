## 安全隐患与疑似 bug（均保留原语义）

- 签名和口令比较已经使用 `hmac.compare_digest`，无需修补；签名构造仍为日期 + HMAC-SHA256。
- `_failures` 无容量上限、无全表清理；低于阈值且不再访问的 IP 可永久留存，大量不同 IP 可使内存增长。状态仅在单进程内，重启清空，多 worker 不共享。
- 无条件信任 `CF-Connecting-IP`，不检查连接来源或地址格式；安全性依赖源站入口隔离及 Cloudflare 对头的处理。能直连源站的客户端可伪造此头绕过按 IP 锁定；仅监听回环并不能证明所有本机调用者都可信。
- 锁定从首次失败计算；未到阈值的旧记录只在下一次失败时重置，精确窗口边界使用 `>`；阈值触发时可能显示 301 秒。这些现有边界未修改。
- 令牌可在有效期内重放，不能单独撤销；共享口令轮换才会统一失效。令牌包含已知日期和签名，弱共享口令存在离线猜测风险。
- 登录 JSON 为非空数组/标量时 `.get()` 可能报错；`compare_digest` 对非 ASCII 字符串可能抛出 TypeError（口令、提交密码或签名），造成 500。仅报告，未改变异常与安全语义。
- OG 根地址使用 Host、`X-Forwarded-Proto` 或显式环境值并直接插入 HTML 属性，依赖入口和值可信；未新增来源校验或转义。
